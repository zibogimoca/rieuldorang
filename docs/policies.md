# 콘텐츠·운영 정책

## 사실과 자료

확인된 건물명, 설명, 사진만 게시합니다. 위치·연혁·수상·연락처 등을 추정해 작성하지 않습니다. 현재 시안은 원본 홈페이지에서 확인한 일부 자료를 사용합니다. 사용 범위와 남은 이관 목록은 `content-inventory.md`에 기록합니다. 원본은 최초 요청에서 HTTP 403이었으나 재시도에서 정상 접근했습니다.

사진·도면·글은 직접 제작했거나 사용 허락을 받은 자료만 사용합니다. 출처, 권리자, 허락 범위는 운영자가 별도 기록하고, 공개할 수 있는 출처 정보는 필요에 따라 소개에 적습니다. 인물·차량번호·사적 공간 등 개인정보가 담긴 자료는 공개 동의와 가림 처리를 확인합니다.

## 개인정보와 외부 서비스

현재 사이트에는 문의 폼, 로그인, 분석 도구, 쿠키 설정 기능이 없습니다. 호스팅 사업자의 접근 로그 처리는 별도 확인 대상입니다. 이 문서는 법적 개인정보처리방침을 대신하지 않습니다. 개인정보 수집이나 외부 서비스를 추가할 경우 목적·항목·보관 기간·처리 주체·동의 필요 여부를 검토하고 사용자에게 필요한 안내를 제공한 뒤 배포합니다.

## 변경과 공개

자료 작성 → 사실·권리 검토 → 빌드와 화면 확인 → 변경 검토 → 배포 순서로 진행합니다. 오류를 발견하면 해당 항목을 수정하거나 공개 목록에서 내린 후 원인을 기록합니다. `published: false`인 자료도 배포 파일에서 비밀로 보장되지 않으므로 민감한 자료를 넣지 않습니다.

## 문서 관리

폴더 구조가 바뀌면 `architecture.md`, 개발 절차는 `development-rules.md`, 콘텐츠 필드는 `content-guide.md`를 업데이트합니다. 운영 정책 변경은 실제 기능과 일치하는지 함께 검토합니다.
